Privacy Policy — BonsaiViu (English Version)

Last updated: October 23, 2026

1. Introduction

This Privacy Policy explains how BonsaiViu handles user data. It applies to the BonsaiViu mobile application published on Google Play.

BonsaiViu respects Google Play’s User Data Policy and Data Safety requirements.

2. Data Collection

BonsaiViu does not collect any personally identifiable information such as name, email, phone number, address, or unique device identifiers.

However, the app accesses certain data strictly necessary for its core functionality, as described below.

3. Access to Photos and Local Files

3.1 Access to Photos (Permissions: READ_MEDIA_IMAGES / READ_EXTERNAL_STORAGE)

BonsaiViu accesses photos only when the user selects an image from their device to attach it to a bonsai entry or to illustrate content inside the app.

  • Photos are not collected, not uploaded, and not shared.
  • Images remain entirely local on the user’s device.
  • The app does not scan, analyze, or access any other media files beyond the one explicitly chosen by the user.

3.2 Local File Storage

BonsaiViu may create and store local files on the device (e.g., app data, local backups, internal cache).

  • These files are stored locally and are never transmitted to any server.
  • All locally stored data is removed when the user uninstalls the app.

4. Technical Data

The app may generate non‑personal technical data such as:

  • Android version
  • App version
  • Local crash logs

These remain on the device and are not sent to any external service.

5. How Data Is Used

Data accessed by BonsaiViu is used solely for:

  • allowing the user to select and display photos;
  • saving local app data;
  • improving app stability.

No data is used for advertising, analytics, profiling, or commercial purposes.

6. Data Sharing

BonsaiViu does not share any data with:

  • third parties
  • advertisers
  • analytics providers
  • external SDKs

The app does not include any third‑party libraries that collect or transmit user data.

7. Data Storage and Security

All data remains local on the user’s device. No network communication or remote storage is used.

8. User Rights

Since BonsaiViu does not collect personal data:

  • no user account is required;
  • no personal data is stored on servers;
  • users control all local files directly on their device.

9. Children

BonsaiViu does not specifically target children. A privacy policy is provided to comply with Google Play requirements.

10. Changes to This Policy

Any future updates to this Privacy Policy will be posted on this page and reflected within the app.

11. Contact

For questions about this Privacy Policy, please contact: bonsaiviu@gmail.com
